# The Next Ball — Website V1

Production starter for thenextball.com.

## Stack
- Next.js
- TypeScript
- Plain CSS design system (no UI framework dependency)

## Current scope
This first build establishes:
1. Navigation
2. Hero
3. Disruption / “GOOD. NOW WHAT?”
4. Core principle
5. Darren introduction
6. Speaking
7. Book
8. Final “WHAT’S YOUR NEXT BALL?”

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Brand rules
- Court Cream #F4F0E6
- Deep Court #132033
- Next Ball #C7F238
- Line White #FFFEF8
- Baseline Grey #7B807F
- Lime means action.
- Real Darren first. AI around Darren, not instead of Darren.
- No generic SaaS cards, gradients, glassmorphism or motivational-speaker styling.
